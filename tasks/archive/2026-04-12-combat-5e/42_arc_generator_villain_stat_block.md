# Task 42 — Arc generator : stat block complet du villain

**Phase** : 4 — Interprète & générateurs LLM (parallèle)
**Dépendances** : [10](10_npc_stat_block_model.md)
**Coordinateur** : [tasks/combat/README.md](README.md)

## Contexte

L'arc generator ([ai/arc_generator.py](../../ai/arc_generator.py) + [ai/prompts/system_arc_generator.txt](../../ai/prompts/system_arc_generator.txt)) produit aujourd'hui un `StoryArc` avec `theme, premise, beats, villain_name, villain_motivation`. Le villain n'a **qu'un nom et une motivation** — aucun stat block.

Pour que le villain ait ses signatures custom, legendary actions, phases (tier boss du plan coordinateur), l'arc generator doit produire **le stat block complet du villain** dans le JSON output, au moment où il invente le villain. C'est le seul moment où le LLM a le contexte narratif pour créer des capacités thématiques ("Chant du Silence Éternel" pour Vellus le Mentisseur, pas pour un goblin).

## Scope

1. Étendre `ai/prompts/system_arc_generator.txt` pour demander un `villain_stat_block` dans le JSON output, suivant exactement le schéma `NPCStatBlock` (tier=boss).
2. Ajouter `villain_stat_block: NPCStatBlock | None` à `StoryArc` (ou au modèle intermédiaire utilisé par l'arc generator).
3. Parser et valider dans `ai/arc_generator.py`. En cas d'échec de validation, fallback sur `engine.npc_library.get_archetype("generic_boss")`.
4. Propager le stat block vers `bot/scene_hydration.py` (tâche [43](43_hydration_dispatches_tier.md)) pour qu'il soit attaché à l'NPC du villain quand il est hydraté dans la location.

## Implémentation — esquisse

```python
# world/story_arc.py
from engine.npc_stat_block import NPCStatBlock

class StoryArc(BaseModel):
    # ... existing fields ...
    villain_name: str
    villain_motivation: str
    villain_stat_block: NPCStatBlock | None = None
    """Full combat stat block for the villain, generated by the arc
    generator LLM. If None (generation failure or legacy arc), the
    hydration layer will fall back to the generic_boss archetype."""
```

**Prompt — section à ajouter** dans `system_arc_generator.txt` :

```
## Villain stat block (mandatory for the villain_name)

Le villain produit pour cet arc doit avoir un `villain_stat_block` complet
en JSON qui permet à l'engine de jouer un vrai combat final contre lui.

Format :
"villain_stat_block": {
  "tier": "boss",
  "archetype": "<une catégorie : mage, warrior, priest, lord, etc.>",
  "multiattack_count": 3,
  "attacks": [
    {
      "name": "<nom d'attaque avec saveur>",
      "damage_dice": "<ex: 1d8+4>",
      "damage_type": "<slashing|piercing|bludgeoning|fire|cold|poison|...>",
      "to_hit_bonus": 7,
      "range_type": "melee|ranged|reach",
      "range_value": null
    }
  ],
  "signature_abilities": [
    {
      "name": "<nom unique avec saveur narrative>",
      "description": "<1-2 phrases décrivant l'effet>",
      "usage": "per_combat|at_will|recharge_5_6",
      "uses_remaining": 1,
      "is_reaction": false,
      "action_cost": "action|bonus|reaction",
      "effects": [
        {
          "kind": "damage|heal|condition|aoe_damage|buff|debuff|move",
          "dice": "<ex: 3d10>",
          "damage_type": "...",
          "condition_name": "frightened|poisoned|stunned|...",
          "condition_duration_rounds": 3,
          "save_ability": "STR|DEX|CON|INT|WIS|CHA",
          "save_dc": 15,
          "target_scope": "single|zone|all_enemies|self"
        }
      ]
    }
  ],
  "legendary_actions": [
    {
      "name": "<ex: Coup du Ténébreux>",
      "cost": 1,
      "description": "<une phrase>",
      "effects": [<même format que signature effects>]
    },
    {
      "name": "<ex: Déplacement Ombreux>",
      "cost": 2,
      "description": "<une phrase>",
      "effects": []
    },
    {
      "name": "<ex: Fracas Éternel>",
      "cost": 3,
      "description": "<une phrase>",
      "effects": [<effet lourd>]
    }
  ],
  "legendary_points_per_round": 3,
  "phases": [
    {
      "trigger_hp_percent": 50,
      "narrative_cue": "<description du moment où le villain change de phase>",
      "unlock_signatures": ["<nom d'une signature supplémentaire>"],
      "attack_bonus": 2,
      "save_bonus": 2
    }
  ],
  "behavior_profile": "aggressive|defensive|support|tactical",
  "aggression_threshold": 25
}

Règles strictes :
- `tier` doit être exactement "boss".
- `multiattack_count` entre 2 et 4.
- **2 à 3 signature_abilities custom** avec des noms thématiques pour
  le villain (pas "Attack" ou "Heavy Strike" — quelque chose d'unique
  qui reflète sa personnalité et son pouvoir). Exemple pour "Vellus
  le Mentisseur" (désert, mensonges) : "Chant du Silence Éternel",
  "Morsure du Sable", "Voile de Poussière".
- **Exactement 3 legendary_actions** avec coût 1, 2, et 3.
- **1 à 2 phases** avec `trigger_hp_percent` à 50 typiquement.
- Tous les `damage_type`, `condition_name`, `save_ability` doivent
  provenir des enums de l'engine (voir exemples ci-dessus, respecter
  la casse).
- Le stat block doit être **jouable** : dégâts cohérents avec un boss
  de niveau 5-7, AC implicite haut, saves modérés.
- Si tu ne peux pas produire un villain stat block valide, produis
  toujours au moins la structure minimale avec `multiattack_count=2`
  et une seule signature — mieux qu'un stat block manquant.
```

**Parser** dans `ai/arc_generator.py` :

```python
from engine.npc_stat_block import NPCStatBlock
from engine.npc_library import get_archetype
from pydantic import ValidationError

# ... après le parsing existant des autres champs ...

raw_stat_block = data.get("villain_stat_block")
villain_stat_block: NPCStatBlock | None = None
if raw_stat_block is not None:
    try:
        villain_stat_block = NPCStatBlock.model_validate(raw_stat_block)
    except ValidationError as exc:
        logger.warning(
            "Invalid villain_stat_block from arc generator, falling back to "
            "generic_boss archetype. Error: %s", exc,
        )
        villain_stat_block = None

if villain_stat_block is None:
    villain_stat_block = get_archetype("generic_boss")
    # Optionally tweak the archetype name to match the villain
    villain_stat_block.archetype = f"generic_boss:{data.get('villain_name', 'unknown')}"

arc = StoryArc(
    # ... existing fields ...
    villain_name=data["villain_name"],
    villain_motivation=data["villain_motivation"],
    villain_stat_block=villain_stat_block,
)
```
